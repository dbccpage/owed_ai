## Thirty seconds for a recruiter

preserves three rows and 100000 cents, but ownership is underdetermined. Two checked
mappings demonstrate the missing distinction. Select **Obtain selected evidence and

the destination back independently. Export or replay the receipt.

1. Inspect the shuffled source and destination rosters; no crosswalk is in the
   evaluator's initial observations. The initial candidate is a deliberately
   insufficient deterministic fixture, not a measured model mistake.
2. Inspect the witness: two bijections obey the same observations while disagreeing
   about an owner's destination. A direct checker verifies the certificate.
3. Inspect the selected action. A repeated total has no distinguishing power;
   deterministic finite-menu selection chooses a discriminating observation.
4. Inspect the repaired plan, original-plan mismatch, committed rows and separate
   property results. Simulated admission binds candidate, evidence, scope and policy.
5. Replay without database execution or external queries. Change the snapshot:
   the old receipt stays valid for its old scope and becomes inapplicable now.
6. Try missing, stale and contradictory evidence. Stale evidence can be refreshed;
   unavailable evidence leaves an obligation; conflicts never authorize a repair.
7. Inspect the three Lean statements. They prove a model boundary, not arbitrary
   Python or SQL. Source-bound build evidence is checked without compiling per click.
