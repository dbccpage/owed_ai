# Five-minute hiring-manager walkthrough

**0:00 — The question.** Open Overview. “This project makes proposals, evidence, unresolved obligations, and permission to act independently inspectable.” Explain that the three labs share one engine and one receipt format.

**0:30 — A valid result can leave an obligation.** Open Evidence with total-only input. Show 121 compatible states: 101 support individual nonnegativity and 20 refute it. The result is underdetermined. Expand the witnesses. These counts are not probabilities about the world.

**1:15 — Resolve evidence without granting authority.** Select `B = 20`: the claim becomes supported. As viewer, release remains denied. Switch the simulated actor to operator. Then show `B = −20`: the claim is refuted. A waiver would not create evidence; this release does not implement waivers.

**2:00 — Locally valid pieces can conflict.** Open Composition. Explain the three edges in plain language. Show the nonzero cycle residual. Run a configured live model to propose a repair, or inspect the included live bundle. The checker verifies the new graph; the original stays visible. No minimum-repair claim is made.

**2:45 — A model does not judge or promote itself.** Open Revision. Show the protected core and editable instructions. Start one bounded run. Two development answers inform one child; the withheld comparison happens only afterward. While it runs, inspect a previously recorded result.

**3:45 — The result may be a tie.** Show parent/child counts, exact case outcomes, and ancestry. A passing candidate remains unadmitted. Admission requires a separate operator action. Emphasize that four synthetic cases and verdict-only scoring do not prove general improvement.

**4:20 — Reproducibility and engineering.** Export the run and verify offline replay. Show the Lean supplement's scoped check and source-bound axiom audit. Explain request budgets, cancellation, independent checkers, and absence of credentials in receipts.

**4:50 — Close with the decision.** “The contribution is an executable boundary: what the agent proposed, what was checked, what it still owes, and who may act.” Invite inspection of a failure, not just the successful branch.
